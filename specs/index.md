# Specs Index

All specifications live in this directory. New specs must follow the naming
convention: `<descriptive-identifier>.md` (e.g., `session-naming.md`,
`dashboard-v2.md`). Reviews go in `reviews/`, prefixed with the spec they
reviewed (e.g., `reviews/jira-board-generator-review.md`).
